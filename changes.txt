KSubMaker 변경 이력
====================

1.2.0 (2026-09-26)
------------------

[새 기능]

* 원어 자막도 함께 저장 (설정 -> 자막/출력)
    음성 인식 결과를 감지된 언어 이름으로 한국어 자막과 같은 폴더에 저장합니다
    (영상이름.ja.srt). 다음에 같은 영상을 다시 처리할 때 이 파일을 원본으로
    써서 음성 인식을 건너뛸 수 있습니다.

[버그 수정]

* GTX 10 시리즈(파스칼)에서 로컬 LLM 번역이 실패하던 문제
    번역 단계에서 "번역 서버가 시작 도중 종료되었습니다" 로 멈추던 증상입니다.
    함께 넣던 llama.cpp 가 CUDA 13 으로 만들어져 있었는데, CUDA 13 은 GTX 10
    시리즈를 더 이상 지원하지 않습니다. CUDA 12 빌드로 바꿨습니다.
    그래도 GPU 로 띄우지 못하는 경우에는 실패시키지 않고 CPU 로 한 번 더
    시도합니다 (느리지만 완주합니다).

* GTX 10 시리즈에서 음성 인식 모델을 불러오지 못하던 문제
    "Requested float16 compute type..." 오류로 10% 에서 멈추던 증상입니다.
    이 세대는 float16 연산이 느리거나 지원되지 않아, 연산 방식을 자동으로
    두면 int8 을 고르도록 바꿨습니다.

* 로컬 LLM 구성 요소를 내려받지 못하던 문제
    llama.cpp 저장소의 릴리스 구조가 바뀌면서 설치 스크립트가 파일을 찾지
    못하고 있었습니다.


1.1.0 (2026-09-05)
------------------

[새 기능]

* 영상 옆 자막 파일을 원본으로 번역
    movie.ja.srt 처럼 영상 옆에 원문 자막이 있으면 음성 추출과 인식을
    건너뛰고 그 자막을 바로 번역합니다. 전체 처리 시간의 60% 이상을
    차지하는 두 단계가 통째로 빠집니다.
    어느 자막을 쓸지는 설정된 원본 언어 > 일본어 > 영어 > 기타 > 언어 표기
    없음 순으로 고릅니다. 한국어 자막은 이 프로그램의 결과물이므로 원본으로
    쓰이지 않습니다.

* 결과 자막을 별도 폴더에 저장
    비워 두면 지금까지처럼 영상 옆에 저장하고, 지정하면 원본 폴더 구조를
    그 아래에 그대로 만들어 저장합니다. 다른 폴더의 같은 이름 영상이 한
    경로로 겹치지 않습니다.

* 결과 파일의 언어 태그를 비울 수 있음
    비우면 영상이름.srt 로 저장됩니다. 다만 Plex, Jellyfin 같은 프로그램은
    언어 태그가 있어야 자막을 자동으로 인식합니다.

* 큐가 도는 동안 절전 방지, 다 끝나면 절전 / 최대 절전 / 시스템 종료
    실행 중에는 시스템이 잠들지 않습니다(모니터는 그대로 꺼집니다).
    작업이 스스로 다 끝났을 때만 동작하며, 직접 누른 중단이나 일시정지
    뒤에는 실행되지 않습니다. 실행 직전 30초 취소 카운트다운이 있습니다.

* 파일과 폴더를 목록에 끌어다 놓기
    탐색기에서 영상 파일이나 폴더를 큐 목록에 끌어다 놓으면 추가됩니다.

* 목록에서 바로 파일 다루기 (우클릭)
    이 파일만 실행, 재생, 이름 바꾸기, 삭제(휴지통), 속성.
    작업마다 메모를 남길 수 있고, 용량 열이 추가됐습니다.

* 음성 인식 힌트 입력란
    등장인물 이름이나 고유명사의 표기를 잡아줍니다. 다만 Whisper 구조상
    영상 도입부에만 적용되며 이후 구간에는 영향을 주지 않습니다.

* 화면 재구성
    상단 메뉴 바(설정, 모델 관리, 로그 보기)와 그룹으로 나뉜 명령 바.
    "테스트" 버튼으로 영상 앞부분(30초~10분)만 잘라 빠르게 시험할 수
    있습니다. 시작 버튼은 항상 전체를 처리합니다.

* 모델 추가
    NLLB-200 3.3B (6.7GB)  - 지금 쓰는 1.3B 의 원본 크기 모델
    Qwen3 4B Instruct      - Qwen2.5 3B 의 후속 세대
    EXAONE 3.5 7.8B        - LG AI Research 의 한국어 중심 모델
    셋 다 아직 품질을 측정하지 않았습니다. 기본값은 바뀌지 않았습니다.

[개선]

* 자막 설정을 두 가지로 나눔
    "무엇을 번역할지"(번역 원본)와 "처리할지 말지"(이미 자막이 있는 파일)가
    한 드롭다운에 섞여 있어, "자막 파일을 번역하되 한국어가 이미 있으면
    건너뛴다" 같은 조합을 고를 수 없었습니다. 이제 따로 고릅니다.
    스캔 옵션의 "이미 한국어 자막이 있으면 건너뛰기" 체크박스는 아래쪽
    드롭다운으로 흡수됐습니다. 기존 설정은 자동으로 옮겨집니다.

* 큐 조작 용어 정리
    재시도 -> 다시 넣기, 취소 -> 건너뛰기, 완료 항목 제거 -> 완료 항목
    비우기, 선택 항목 제거 -> 목록에서 빼기.

* 창 닫기(X)가 한 번에 반응
    이전에는 정리가 끝날 때까지 창이 그대로 있어 두 번 눌러야 하는 것처럼
    보였습니다. 창은 즉시 사라지고 정리는 뒤에서 끝납니다.

* 프로그램 아이콘 추가

[버그 수정]

* 자막이 영상보다 먼저 끝날 수 있던 문제
    음성 추출이 영상 파일이 보고하는 길이만큼만 잘라내고 있었습니다.
    그 길이가 실제보다 짧게 적힌 파일에서 자막이 중간에 끊겼습니다.

* 원본으로 읽는 자막을 결과로 덮어쓸 수 있던 문제
    언어 태그를 비우고 충돌 처리를 "덮어쓰기"로 두면, 번역의 원본으로 쓴
    자막 파일 위에 결과를 써서 원본이 사라질 수 있었습니다.

* 네트워크 공유 폴더(UNC 경로)의 결과가 겹치던 문제
    별도 출력 폴더를 쓸 때, 서로 다른 공유에 있는 같은 이름 폴더가
    한 경로로 합쳐졌습니다.

* Kotoba-Whisper 선택 시 프로그램이 종료되던 문제
    이 모델이 지원하지 않는 단어 단위 타임스탬프를 요구해 작업 프로세스가
    강제 종료됐습니다. 해당 모델에서는 자동으로 꺼집니다.

* Windows Store 의 가짜 python3.exe 를 잘못 찾던 문제


1.0.0 (2026-08-15)
------------------

첫 정식 버전. 폴더 검색부터 한국어 자막 생성까지 전 구간이 동작합니다.
자세한 내용은 docs/ 폴더의 문서를 참고하세요.
